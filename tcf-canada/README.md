# TCF Canada 核心词表（目标 NCLC 7+）

针对 **TCF Canada** 设计，不是通用法语词表，也不是 TCF tout public / DELF 的词表。
三语对照：`français` → `English` → `中文`。

**1113 条**，词汇难度刻意控制在 **B2 区间**（对应 NCLC 7），不堆 C1 词——
背了考场上用不到，反而挤占时间。

三个刻意的取舍：

1. **加拿大与魁北克用法单独成块**（`CANADA`，58 条），并且散落在各主题模块里。
   TCF Canada 的听力和阅读材料大量使用加拿大法语，`courriel`、`stationnement`、
   `déjeuner/dîner/souper`、`soumission`、`cégep`、`CHSLD`、`CNESST`、`préposé aux bénéficiaires`
   这些和法国法语不一样的地方，用法国教材是背不到的。
2. **功能语块和论证结构占了 136 条**（`EO1` `EO2` `ARGU` `EE`）。
   NCLC 7 的瓶颈从来不是词汇量，是 Expression écrite 和 Expression orale 这两项
   （各 /20 分）。这两项靠的是现成句型，不是生词。
3. **语法单独成模块**（`CONJUG` 54 条 + `GENRE` 50 条 + `PIEGES` 16 条）。
   EE 和 EO 扣分的大头是变位错、时态错、阴阳性错，不是词汇量不够。
   名词一律带冠词（`le loyer` / `la caution`），背裸词等于没背。

只有 `le préavis` 一条在两个模块各出现一次：在 `TRAVAIL` 指劳动合同的离职通知期，
在 `COCE` 指规章要求的提前告知期，词同义不同。

## 文件

| 文件 | 用途 |
|---|---|
| `_src.psv` | 唯一数据源，`\|` 分隔。要增删词条改这个文件 |
| `tcf-canada-vocab.tsv` | 制表符分隔，直接导入 Anki / Excel |
| `tcf-canada-vocab.md` | 按模块分组的阅读版 |

改完 `_src.psv` 后在项目根目录跑 `bash tools/build.sh`。

字段顺序：`section / theme / fr / pos / en / zh / note / exemple`

## 分数目标

TCF Canada 各项对应 NCLC 的大致区间（**请以 IRCC 官网 Language test equivalency charts 为准**）：

| NCLC | Compréhension orale (0–699) | Compréhension écrite (0–699) | Expression écrite (0–20) | Expression orale (0–20) |
|---|---|---|---|---|
| 10 | 549+ | 549+ | 16–20 | 16–20 |
| 9 | 523–548 | 524–548 | 14–15 | 14–15 |
| 8 | 503–522 | 499–523 | 13 | 13 |
| 7 | 458–502 | 453–498 | 11–12 | 11–12 |

**四项全部 NCLC 7 是硬门槛**——法语类别专项抽签要求四项都达标，一项不到全部作废。
先保四项到 7，再考虑单项冲高。

## 考试结构与模块对照

| 分项 | 形式 | 本表对应模块 |
|---|---|---|
| Compréhension orale | 39 题选择，约 35 分钟。材料为交通与公共场所**公告**、日常与职场**对话**、**演讲/陈述** | `COCE` + 全部主题模块 |
| Compréhension écrite | 39 题选择，60 分钟。材料为**小广告**、**须知**、**新闻报道**、**官方文件节选** | `COCE` + 全部主题模块 |
| Expression écrite | 3 个任务，60 分钟 | `EE` + `ARGU` + `CONJUG` + `GENRE` |
| Expression orale | 3 个任务，约 12 分钟 | `EO1` `EO2` `ARGU` + `CONJUG` |

三个写作任务：**Tâche 1**（60–120 词，信息性短消息）→ `EE` 的 Tâche1 各小类；
**Tâche 2**（120–150 词，叙述经历并加评论）→ `EE` 的 Tâche2-叙事 + `CONJUG` 的 PC/imparfait 对立；
**Tâche 3**（120–180 词，比较两个观点并表态）→ `ARGU` 全部。

三个口语任务：**Tâche 1**（无准备，自我介绍问答）→ `EO1`；
**Tâche 2**（角色扮演，主动提问获取信息）→ `EO2`；
**Tâche 3**（独白，表达观点）→ `ARGU`。

## 建议的背诵顺序

1. **`EO1`**（14 条）——Tâche 1 完全可预测，一天背完，考场上不会冷场。
2. **`EO2`**（28 条）——Tâche 2 的提问句型，练到脱口而出。只有 2 分钟准备时间，
   临场组句必然卡顿，而流利度是评分项。
3. **`ARGU`**（49 条）——笔试 Tâche 3 和口试 Tâche 3 共用。两项各 /20 的分都靠它。
4. **`EE`**（45 条）——书信套语和叙事时间线。
5. **`CONJUG` + `GENRE` + `PIEGES`**（120 条）——这不是词汇，是 EE/EO 的固定扣分点。
   重点是三件事：复合过去时 vs 未完成过去时的对立（Tâche 2 的语法主干）、
   虚拟式触发词、名词阴阳性。做完这一步 EE/EO 能稳在 11–12 分。
6. **`CANADA`**（58 条）——听力和阅读的理解障碍主要来自这里。
7. **`COCE`**（35 条）——公告体和小广告体的固定表达，CO/CE 两项直接受益。
8. **`ABSTRAIT`**（106 条）——把 Tâche 3 的表达从"能说清楚"推到"说得有分量"，
   同时抬高 CE 新闻类文本的理解上限。
9. **主题模块**（657 条）——`TRAVAIL` / `LOGEMENT` / `SANTE` / `ARGENT` 优先（283 条），
   这四块覆盖 TCF Canada 绝大部分题材；其余按 `QUOTIDIEN` → `SOCIETE` → `TRANSPORT`
   → `EDUCATION` → `NUMERIQUE` → `ENVIRO` 的顺序补。

## 用法要点

- `note` 列标了大量**加法差异**和**语法触发条件**。比如 `bien que` 后接虚拟式、
  `même si` 后接直陈式，`espérer que` 后接直陈式，这类信息比中文释义重要得多。
- 标 `expr.` 的条目整句背，不要拆。EE 和 EO 评分看的是能否自然产出完整表达。
- `CONJUG` 模块的 `note` 列直接给出了动词的关键变位形式（现在时、复合过去时分词、
  未完成过去时、简单将来时、虚拟式），当速查表用。
- `GENRE` 模块前 16 条是**词尾规则**，背规则比背单个词高效得多，
  `-tion` `-té` `-ure` `-ance` 全阴性、`-ment` `-age` `-eau` `-isme` 全阳性，
  这几条就能覆盖法语大部分抽象名词。
