# TCF Canada 短语表

针对 **TCF Canada** 的短语与功能语块部分，不是通用法语词表。
三语对照：`français` → `English` → `中文`。

**678 条**，词汇难度刻意控制在 **B2 区间**（对应 NCLC 7）。

这是原 `tcf-canada` 总表拆出来的两半之一。拆分规则很机械：
**去掉冠词后还剩两个及以上词的条目全在这里**——整句的功能语块
（`Je vous prie de bien vouloir`）、话语连接词（`D'une part … d'autre part`）、
动词搭配（`tenir compte de`）、名词复合词（`la résidence permanente`、
`le permis de travail`）、语法规则标题（"虚拟式触发词"）都在本表。
单个词去隔壁 [`tcf-canada-mots`](../tcf-canada-mots/) 单词表。

两个刻意的取舍：

1. **功能语块占了 130 条**（`EO1` `EO2` `ARGU` `EE` 的大部分）。
   NCLC 7 的瓶颈从来不是词汇量，是 Expression écrite 和 Expression orale 这两项
   （各 /20 分）。这两项靠的是现成句型，不是生词。标 `expr.` 的条目整句背，不要拆。
2. **名词复合词也算短语**。`la tempête de neige`、`faire du bénévolat` 虽然是词典词，
   但按"几个词"数就是多词，和背 `le loyer` 不是一个节奏，所以放在这里。

## 文件

| 文件 | 用途 |
|---|---|
| `_src.psv` | 唯一数据源，`\|` 分隔。要增删词条改这个文件 |
| `tcf-canada-phrases-vocab.tsv` | 制表符分隔，直接导入 Anki / Excel |
| `tcf-canada-phrases-vocab.md` | 按模块分组的阅读版 |

改完 `_src.psv` 后在仓库根目录跑 `bash vocab/tools/build.sh`，再跑 `vp run build:data` 同步到网页。

字段顺序：`section / theme / fr / pos / en / zh / note / exemple`

## 分数目标

TCF Canada 各项对应 NCLC 的大致区间（**换算标准会调整，用之前请核对考试官方说明**）：

| NCLC | Compréhension orale (0–699) | Compréhension écrite (0–699) | Expression écrite (0–20) | Expression orale (0–20) |
|---|---|---|---|---|
| 10 | 549+ | 549+ | 16–20 | 16–20 |
| 9 | 523–548 | 524–548 | 14–15 | 14–15 |
| 8 | 503–522 | 499–523 | 12–13 | 12–13 |
| 7 | 458–502 | 453–498 | 10–11 | 10–11 |

**四项全部 NCLC 7 是硬门槛**——四项都要达标，一项不到整体就作废。
先保四项到 7，再考虑单项冲高。

三个写作任务：**Tâche 1**（60–120 词，信息性短消息）→ `EE` 的 Tâche1 各小类；
**Tâche 2**（120–150 词，叙述经历并加评论）→ `EE` 的 Tâche2-叙事；
**Tâche 3**（120–180 词，比较两个观点并表态）→ `ARGU` 全部。

三个口语任务：**Tâche 1**（无准备，自我介绍问答）→ `EO1`；
**Tâche 2**（角色扮演，主动提问获取信息）→ `EO2`；
**Tâche 3**（独白，表达观点）→ `ARGU`。

## 模块构成

### 功能语块（130 条）

| 模块 | 条数 | 作用 |
|---|---|---|
| `EO1` | 14 | Tâche 1 自我介绍。完全可预测，一天背完 |
| `EO2` | 28 | Tâche 2 角色扮演。这是**提问**任务，不是回答任务，大部分人栽在不会用法语提问 |
| `ARGU` | 45 | Tâche 3 论证结构。笔试口试共用，性价比最高的一块（另有 4 个单词在单词表） |
| `EE` | 43 | 书信套语（称呼、开头、请求、道歉、投诉、结尾、落款）+ 叙事时间线（另有 2 个单词在单词表） |

### 语法规则与搭配（53 条）

| 模块 | 条数 | 内容 |
|---|---|---|
| `COCE` | 32 | 公告体、小广告体、正式文件体的固定表达。CO/CE 的材料就是这些文体（另有 3 个单词在单词表） |
| `CONJUG` | 25 | 时态名称与对立（`passé composé`、`PC vs imparfait`）、虚拟式触发结构（`bien que`、`il faut que`）、中文标题的规则条 |
| `VERBES` | 16 | 高频动词与介词搭配（`s'occuper de`、`tenir à + 原形`……，不带介词的 9 个动词在单词表） |
| `PIEGES` | 9 | 中文标题的语法陷阱条 + `assister à`、`passer un examen`（假朋友单词在单词表） |
| `GENRE` | 3 | 多词的复数规则（`les transports en commun`、`-al → -aux`，单词的全在单词表） |

## 建议的背诵顺序

1. **`EO1`**（14 条）——Tâche 1 完全可预测，一天背完，考场上不会冷场。
2. **`EO2`**（28 条）——Tâche 2 的提问句型，练到脱口而出。只有 2 分钟准备时间，
   临场组句必然卡顿，而流利度是评分项。
3. **`ARGU`**（45 条）——笔试 Tâche 3 和口试 Tâche 3 共用。两项各 /20 的分都靠它。
4. **`EE`**（43 条）——书信套语和叙事时间线。
5. **`CONJUG` + `PIEGES`**（34 条）——EE/EO 的固定扣分点。
   重点是三件事：复合过去时 vs 未完成过去时的对立（Tâche 2 的语法主干）、
   虚拟式触发词、`en / y` 这类代词（代词单词本身在单词表）。
6. **`CANADA`**（22 条）+ **`COCE`**（32 条）——听力和阅读的理解障碍主要来自这里，
   公告体和小广告体的固定表达 CO/CE 两项直接受益。
7. **`ABSTRAIT`**（36 条）——把 Tâche 3 的表达从"能说清楚"推到"说得有分量"。
8. **主题复合词**——`TRAVAIL` / `SANTE` / `ARGENT` 优先，
   这三块覆盖 TCF Canada 绝大部分题材；其余按出现顺序补。

## 用法要点

- `note` 列标了大量**加法差异**和**语法触发条件**。比如 `bien que` 后接虚拟式、
  `même si` 后接直陈式，`espérer que` 后接直陈式，这类信息比中文释义重要得多。
- 标 `expr.` 的条目整句背，不要拆。EE 和 EO 评分看的是能否自然产出完整表达。
- `CONJUG` 模块的中文标题条是规则速查，点进去看 `note` 列的变位表。
- 多词语块没有音标（逐词拼接的音标每个词都带主重音，是错的），靠页面上的 TTS 朗读。
